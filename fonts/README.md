# Website fonts

These unmodified WOFF2 font files are served locally. Each family includes its SIL Open Font License in `OFL.txt`.

Source CSS (downloaded 26 October 2026):

https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500..800&family=Inter:wght@400..700&family=JetBrains+Mono:wght@500..600&display=swap

Families and weights: Bricolage Grotesque 500–800 (optical size 12–96), Inter 400–700, JetBrains Mono 500–600. The CSS retains the upstream Unicode subsets, so browsers load only those required by the page text.
